# Documentação do projeto simpleBash

## Visão geral

O `simpleBash` é um projeto acadêmico e de estudo para a implementação de um shell em linguagem C. O objetivo é criar uma base funcional para execução de comandos, leitura de entrada do usuário e organização de módulos que reflitam a arquitetura de shells reais, com foco em clareza, didática e evolução incremental.

Este diretório centraliza a documentação inicial do projeto, incluindo proposta, requisitos, arquitetura e critérios de aceitação.

## Objetivo do projeto

Desenvolver uma versão inicial de um shell simples, capaz de:

- receber comandos digitados pelo usuário;
- interpretar argumentos e tokens;
- executar comandos internos e externos;
- manter um ciclo de interação até o encerramento do programa;
- servir como base para extensões futuras.

---

## Escopo inicial

O escopo da primeira entrega inclui:

- prompt interativo;
- leitura de uma linha por vez;
- tokenização básica;
- execução de programas externos;
- suporte a comandos internos básicos;
- tratamento inicial de erros.

O escopo não inclui, nesta fase, recursos avançados como pipelines completos, redirecionamento sofisticado, histórico robusto e shell script completo.

---

## Entregáveis esperados

1. Shell funcional em C com loop principal.
2. Estrutura modular do projeto em diretórios e arquivos.
3. Documentação clara da arquitetura.
4. Critérios de aceite definidos para as funcionalidades da primeira versão.

---

## Critério de sucesso

A proposta do projeto será considerada bem-sucedida quando a infraestrutura do shell permitir a execução básica de comandos do sistema operacional com estabilidade, organização e facilidade de manutenção.
